# GEMINI DESIGN PROMPT: Della DIY Mini Split Installation Guide

Use this prompt to generate a full-page long-scroll landing page mockup image only. Do not generate code. Text, product names, prices, warranty claims, policy claims, installation details, and product data in the image are placeholders only. The PRD controls final content, data, safety language, routing, and scope.

## Canvas And Output

- Create one complete desktop long-scroll mockup image.
- Recommended canvas: about 1600px wide and 5200-6500px tall.
- Show the full page from top to bottom, not a cropped hero or partial screen.
- Design for a standalone Shopify custom landing page section.
- Do not include global website header navigation, search, cart, account icon, footer, newsletter footer, or payment icons.
- Leave enough structure and spacing for Codex to recreate the page cleanly in static HTML/CSS.

## Goal

Design a mature Della ecommerce landing page for:

**DIY Mini Split Installation Guide**

Page type:

**Installer-support research landing page + light collection-support page.**

The page should support SEO research traffic and Google/Facebook ad visitors. It should help users decide what they can plan themselves, what they need to confirm before checkout, what tools/parts may be needed, and when to use Della support or a qualified HVAC professional.

The page should not feel like a generic blog article, a SaaS dashboard, a coupon page, or a hard-sell product collection.

## Brand And Visual System

Use Della PageFly / Memorial / coupon-code topical visual language:

- Heading and product title font: Spectral or similar refined serif.
- Body, buttons, labels, tabs: Poppins or similar clean sans-serif.
- Primary navy: `#0E1953`.
- Brand blue: `#5884E7`.
- Blue hover/accent: `#6B95EF`.
- Light blue surfaces: `#EDF2FF`, `#F4F7FF`, `#DDF7FF`.
- White cards, clean product media areas, restrained borders, minimal shadows.
- Buttons: rectangular with 4px radius, not pill-shaped.
- Overall feel: polished Shopify DTC ecommerce guide, visual and trustworthy, not generic AI template.

Uploaded Della screenshots, PageFly references, coupon-code references, product references, or Della assets are visual references only. Do not copy promo copy, prices, warranty/policy claims, exact product data, sale treatments, countdowns, coupon codes, or unsupported installation claims from reference images.

Hero should be a Della ecommerce banner:

- Left side: H1, short supporting copy, two CTAs.
- Right side: product-led installation planning visual.
- Show a wall-mounted Della-style mini split, installation checklist/tablet, line-set route cue, outdoor unit or tool setup.
- Include a few subtle static cue chips such as `Line set route`, `Voltage check`, `Drainage`, `Installer support`.
- Keep text readable and uncluttered.

## Audience And Intent

Audience:

- homeowners researching DIY mini split installation
- shoppers deciding what tools and accessories are needed
- users worried about line sets, voltage, drain route, permits, and whether they need a technician
- paid-ad visitors who need confidence before shopping

Core decision:

**Can I plan a DIY mini split install, and what should I buy or confirm before checkout?**

## Required Section Order

Design a full-page mockup with these sections in order:

1. **Slim benefit strip**
   - Free Shipping Sitewide
   - Find Partner HVAC Installer
   - 24/7 Live Chat Support
   - Keep it slim and trust-focused, not promotional.

2. **Hero: DIY Mini Split Installation Guide**
   - H1: `DIY Mini Split Installation Guide`
   - Short copy: plan the system, tools, line set, electrical checks, and support path before you start.
   - CTA 1: `Start the Install Checklist`
   - CTA 2: `Shop Installation Essentials`
   - Visual: Della-style mini split + installation planning scene.
   - No product card in hero.

3. **Early path selector: Choose your installation path**
   - Compact path cards:
     - I need a mini split system
     - I'm planning a wall-mounted install
     - I need parts and accessories
     - I need install tools
     - I may need a pro
   - Cards should feel like navigation/decision cards, not PDP cards.

4. **Decision band: What DIY usually means — and what to confirm first**
   - Three columns:
     - Good DIY planning tasks
     - Needs careful verification
     - May require a licensed pro
   - Keep copy short and scannable.
   - This section should communicate safety boundaries without feeling alarming.

5. **High-level install steps: Mini split install steps at a glance**
   - Show an overview sequence, not a detailed technical manual.
   - Include a side note or mini card: use the exact model manual.
   - Include a visual cue for manuals/support.

6. **Tools & parts checklist: What you may need before install day**
   - Three groups:
     - System parts
     - Mounting and routing
     - Setup tools
   - Route visually toward Accessories, Line Set, and Rental Install Kit.
   - Use a focused checklist panel, not a huge generic icon grid.

7. **Before checkout checklist: Confirm these before you order**
   - Use a left image/right checklist or similar high-quality ecommerce module.
   - Include voltage, dedicated circuit/panel capacity, line-set compatibility, drain route, outdoor clearance, wall route, permits/HOA, indoor airflow, manual compatibility.

8. **Shop the installation essentials**
   - Use 3-4 low-pressure product/collection cards:
     - DELLA Rental Install Kit
     - DELLA Mini Split Line Set
     - Installation Accessories
     - Wall-Mounted Mini Splits
   - Card CTAs should be `View Rental Kit`, `View Line Set`, `Shop Accessories`, `Shop Wall-Mounted Systems`.
   - Cards should borrow Della product-card grammar but not look like a sale grid.

9. **Choose the system around the install**
   - Cards for:
     - Wall-mounted
     - Multi-zone
     - Ceiling cassette / concealed ducted
     - Accessories
   - Emphasize installation planning complexity, not BTU.

10. **Install help hub**
   - Four support cards:
     - Watch installation videos
     - Read manuals & troubleshooting
     - Find a partner HVAC installer
     - Contact Della support / live chat
   - Make this feel like an official support confidence module, not footer links.

11. **FAQ**
   - Compact accordion look.
   - 6 questions max.
   - Keep it near the bottom.
   - Suggested FAQ topics: can I install a mini split myself, tools needed, vacuum pump, choosing a line set, what to check before ordering, warranty/support impact.

12. **Bottom CTA**
   - Heading: `Ready to plan your mini split install?`
   - Buttons:
     - Shop Mini Split Systems
     - Shop Installation Accessories
     - Find Partner HVAC Installer

## Ecommerce Intensity

Use a content-driven DTC landing-page rhythm:

- Decision and planning first.
- Product/collection cards only after the visitor understands the install path.
- Product cards should be limited to installation essentials and key system paths.
- Do not make BTU collections the primary structure.
- Do not use a large mini split product wall.
- Do not use `Add To Cart`.
- Use `View Product`, `Shop Options`, `Shop Accessories`, or support CTAs.

## Mobile Expectations

Design mobile behavior in the mockup:

- Hero copy should remain readable and primary.
- Path selector can become a horizontal snap row.
- Cards should be compact with clear tap targets.
- Tables/checklists should stack cleanly.
- Product cards can stack one column if text needs room.
- No text overlap, clipped buttons, cramped tables, or unreadable cue chips.
- If mobile is implied in the design, prioritize readable hierarchy over showing every desktop chip.

- calculator hero

- glassmorphism
- decorative orbs or bokeh blobs
- generic oversized icon grids
- heavy shadows

- countdown timers
- `Add To Cart`
- fake discounts

- legal/code guarantees
- "anyone can install without a pro" messaging

- detailed electrical wiring steps

- 3D dashboard widgets
