## 图片去底与尺度

Compare 和 Explore 两个模块使用同一批产品原图的透明衍生文件。11 个 ID 中有 8 份唯一原图；p02/p03、p06/p08、p09/p10 分别共享相同原文件，衍生图也应一致。

用户已授权沿用 Whole House 的程序化精确抠图方式。采用保守的边缘连通背景遮罩、产品内部保护区和 0.35px 透明度羽化；RGB 保持原值，原 JPG 保留。透明 PNG 在 assets/products-cutout；products.json 的 localImage 已映射，原路径保存在 originalLocalImage。处理和验收证据见 PRODUCT-IMAGE-PROCESSING.md 及 qa/image-refinement-20260917。

比较图尺寸不能只靠背景透明化解决。当前 CSS 的 height/max-height 150px 加上原图外围空白，使产品明显偏小。目标：

- >1100px 比较媒体区域约 280px 高，图像最大宽约 330px且不超过列宽；完整 contain。
- 768–1100px 约 220–240px 高，防止三列宽度不足时拉伸。
- 手机滑动列约 220px 高，保留当前 82% 列宽与箭头方案。
- 同一行共用媒体高度，按实际长宽比显示；不强制所有不同形状机器等宽等高，不裁剪机身来填满。
- 商品卡继续沿用 Whole House 的大图区域，替换为透明衍生图，并让图片和媒体容器融入白底。不要用 CSS blend/filter 伪装抠图。
- 保留适度安全边距，避免贴边后看起来被裁切。
